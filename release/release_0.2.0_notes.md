# ديوني 0.2.0 (رقم البناء 2) — ملاحظات الإصدار

## ما الجديد (للمستخدمين)
- **ترتيب وتصفية الحسابات** في الشاشة الرئيسية: الأحدث، الأقدم، الاسم، الأكبر/الأصغر رصيدًا، آخر نشاط، مع تصفية بحسب الحالة (له / عليه / مسدّد).
- **البحث بالتاريخ** داخل تفاصيل الحساب مع إجمالي له/عليه للفترة.
- **تصفية التقارير حسب حالة الحساب**، وتقرير «إجمالي المبالغ» بجدول مستقل لكل عملة وألوان أوضح.
- **التحويل بين الحسابات.**
- **تذكيرات السداد** لكل حساب (إشعارات).
- **رسائل الرصيد**: إرسال رسالة بالرصيد عبر واتساب أو SMS، وإعدادات **الرسائل التلقائية** عامة وعلى مستوى كل حساب.
- **تحسينات الأوامر الصوتية**: التعرف على اسم العملة من عملاتك أنت، وتحسين كلمة «ديوني»، وبدء استماع أسرع، والتحول للتعرف المحلي عند ضعف الإنترنت، وعدم خفض صوت الجهاز.
- **التحديثات**: عرض رقم الإصدار وفحص وجود إصدار أحدث من «حول التطبيق»، مع إشعار داخل التطبيق عند توفر تحديث.

## للتطوير (داخلي)
- الفرع: `claude/voice-fixes-v4`.
- يتطلب Flutter 3.38.1 أو أحدث (Dart 3.10).
- تغيّر `firestore.rules`: إضافة قراءة عامة لـ `app_config/{doc}` — **يجب نشر القواعد**.

## نص «ما الجديد» لمتجر Google Play (≤ 500 حرف)

**العربية**
```
جديد في ديوني:
• ترتيب وتصفية الحسابات، والبحث بالتاريخ في تفاصيل الحساب
• تقارير أوضح بجدول لكل عملة وتصفية حسب حالة الحساب
• التحويل بين الحسابات وتذكيرات السداد
• رسائل الرصيد عبر واتساب أو SMS مع إعدادات تلقائية
• تحسينات كبيرة في الأوامر الصوتية
• فحص التحديثات من شاشة «حول التطبيق»
```

**English**
```
What's new in Dyooni:
• Sort & filter accounts; search by date inside an account
• Clearer reports: one table per currency, filter by account status
• Transfers between accounts and payment reminders
• Balance messages via WhatsApp or SMS, with automatic settings
• Big voice-command improvements
• Check for updates from the About screen
```

## مستند Firestore الذي يقرؤه التطبيق
المسار: `app_config` ← `release`

| الحقل | النوع | القيمة لهذا الإصدار |
|---|---|---|
| `version` | string | `0.2.0` |
| `build` | number | `2` |
| `minSupportedBuild` | number | `0` (ارفعه ليصبح التحديث إلزاميًا لمن بناؤه أقل) |
| `url` | string | رابط التحميل (المتجر أو صفحة التطبيق) |
| `notes_ar` | array of string | عناصر «ما الجديد» بالعربية (كل نقطة عنصر) |
| `notes_en` | array of string | نفسها بالإنجليزية |
